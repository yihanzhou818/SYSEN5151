# SYSEN 5151 Codex Workflow

Before implementing any feature:

1. Read AGENTS.md.
2. Read SPEC.md.
3. Locate relevant requirements and model artifacts.
4. Extract the implementation-relevant information.
5. Identify constraints.
6. Define the bounded implementation task.
7. Use relevant Skills if appropriate.
8. Implement only the bounded task.
9. Run relevant tests.
10. Review against requirements and interfaces.
11. Reconcile code back to the model.
12. Report assumptions and mismatches.

Never skip directly from requirement to code.
