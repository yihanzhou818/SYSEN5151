# User story map

Derived from UC.1 and stakeholder ST-01. Rows describe intended user value; checks below are for the fixed-fixture increment, not measured MOEs.

| User activity | Story | Action | Need | Chapter 2 slice / acceptance evidence |
|---|---|---|---|---|
| Frame comparison | As a researcher, I select a pair and date for a common basis. | UC.1.1–1.2 | N-01 | Form passes the request separately from fixed fixture dates. |
| Obtain evidence | I want dated records and identifiable sources for both stocks. | UC.1.3–1.4.2 | N-01, N-03 | Both provider stubs feed scoring; source/date handoff test. |
| Compare | I want to inspect scores and drivers. | UC.1.5 | N-01, N-02 | Fixed 60/40 scores and driver labels render. |
| Understand | I want an explanation tied to the displayed scores. | UC.1.6 | N-02 | Fixed explanation receives score-evidence payload. |
| Inspect | I want to review drivers and source dates myself. | UC.1.7–1.8 | N-03 | Dashboard displays source ID and date; human inspection remains a human action. |

Later slices: verified datasets and scoring definitions; real model integration; participant pilot. Report's 80% criteria remain proposed, with no completed pilot claimed.
